# TAREEQ demo video

Builds a captioned demo video of the React app: `output/demo.mp4` (1280x720, 30 fps, H.264 + AAC, about 1:55) and `output/demo.srt`
(the same captions as a separate file). The page is driven by Playwright (real mouse moves, clicks and typing), the captions are burned in
by ffmpeg, and there is quiet background music and no voiceover.

## Re-run it (one command)

```
cd demo
npm install
npm run setup        # once: downloads the Chromium that Playwright uses (about 120 MB)
npm run demo
```

`npm run demo` checks that the frontend is running (and starts `npm run dev` in `../frontend` if it is not), then records, builds and
verifies the video. It needs Node 20 or newer. The frontend needs its `frontend/.env` as usual (`copy frontend\.env.example frontend\.env`).

## What the video shows (about 115 s)

Start screen and options, asking an example question (loading card, answer, numbered sources), the source drawer, a follow-up, a vague
question that is answered through a clarification, a refused question and a "not enough evidence" question, past conversations with
delete and Undo, the Search Inspector (hybrid, lexical, an empty filter result) and the About page.

## How it works

| File | Job |
|---|---|
| `captions.json` | the one place the captions live: `start`, `end` (seconds) and `text` |
| `record.js` | Playwright script that follows the same timeline: each step waits for its time on the clock, so the captions match the action |
| `build.js` | writes `output/demo.srt` from `captions.json`; ffmpeg trims to the start of the timeline, burns the captions into the bottom strip, mixes the music, exports `output/demo.mp4` |
| `verify.js` | ffprobe/ffmpeg checks (resolution, fps, codecs, duration, music level, fades) and extracts one frame per caption to `work/frames/` |
| `capture-fixtures.js` | saves the data the recording uses, in `fixtures/responses.json` |
| `run.js` | `npm run demo`: runs the steps in order |
| `flow.js` | the demo's questions and addresses, shared by the scripts |

Single steps: `npm run capture`, `npm run record`, `npm run build`, `npm run verify`. To change a caption, edit `captions.json` and run
`npm run build` (the recording does not change). To change what happens when, edit the times in `record.js` and keep `captions.json` in step.

Details worth knowing:

- **Sync marker.** Playwright's video starts a little after the page is created, so the script shows a black square in the corner just
  before the timeline starts, and `build.js` finds the frame where it disappears and trims there. (A guessed offset was a second out.)
- **Caption strip.** The page leaves a 100 px dark strip at the bottom (`record.js`) and ffmpeg writes the captions into it, so they never cover the app.
- **Subtitle units.** ffmpeg lays out `.srt` subtitles on a 384x288 canvas and scales them, so `FontSize=12` in `build.js` is about 30 px on 1280x720.
- **Music.** `assets/music.mp3` is an original ambient loop generated by `assets/make_music.py` (numpy), so there is no licence to track: it is
  released as CC0. Replace the file with any other track and run `npm run build`: it is looped or trimmed to the video length, levelled to about
  -18 LUFS, faded in over 2 s and faded out over the last 3 s.
- **Font.** `assets/fonts/Roboto-Medium.ttf` (Apache License 2.0, Google) is used for the burned-in captions.
- **ffmpeg and ffprobe** come from the npm packages `@ffmpeg-installer/ffmpeg` and `@ffprobe-installer/ffprobe`, so nothing needs installing system-wide.

## If something goes wrong

| Symptom | What to do |
|---|---|
| "the frontend did not start" | start it yourself: `cd frontend && npm run dev` (port 5180), then `npm run demo` |
| "No recorded answer for POST ..." | the flow asks for something that is not in `fixtures/responses.json`: run `npm run capture` (the API must be running) after changing the flow |
| Steps "ran late" in the record output | the machine was busy; close other programs and re-record. Late steps shift the action against the captions |
| "Sync marker not found" | the build falls back to an estimate that can be about a second out; re-record |
| Captions too big or too small | change `FontSize` in `build.js` (units explained above) |
